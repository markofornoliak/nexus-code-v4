# NEXUS v3 curriculum inventory — archived

Release 3.0 contains **65 lessons**, **130 required tasks**, and **65 optional bonus
challenges**. Every available world contains five lessons so the visual maps and
progress contracts stay consistent.

| Track       | Runtime                   | Worlds | Lessons |
| ----------- | ------------------------- | -----: | ------: |
| Python Core | Pyodide Web Worker        |      7 |      35 |
| JavaScript  | JavaScript Web Worker     |      2 |      10 |
| HTML / CSS  | Sandboxed live preview    |      2 |      10 |
| Java        | Java 8 source analyzer    |      1 |       5 |
| C++         | C++ source analyzer       |      1 |       5 |
| **Total**   | Four execution strategies | **13** |  **65** |

## Python Core

1. **Signal Awakening** — output, variables, strings, input, and arithmetic.
2. **Logic Chambers** — comparisons, booleans, conditions, nested decisions, and
   loops.
3. **Memory Structures** — lists, tuples/sets, dictionaries, functions, and the
   Archive Scanner capstone.
4. **Data Currents** — comprehensions, exceptions, standard modules, text parsing,
   and data pipelines.
5. **Object Foundry** — classes, methods, properties, inheritance, and dataclasses.
6. **Algorithm Observatory** — complexity, searching, sorting, recursion, and the
   Observatory analyzer capstone.
7. **Systems Laboratory** — assertions, debugging, reliable file handling,
   generators, context managers, and a tested telemetry-recovery capstone.

## JavaScript

**Signal Circuit** covers console output, bindings, arrays, decisions, and loops.
**Reactive Lattice** covers functions, objects, array methods, JSON/error boundaries,
and promises. The Worker supports lesson-level `input()` and top-level `await`.

## HTML / CSS

**Semantic Strata** covers the document skeleton, landmarks, navigation, labeled
forms, and an accessible component capstone. **Responsive Field** covers selectors and
tokens, the box model, Flexbox, Grid, and responsive/reduced-motion design.

The preview iframe has an empty sandbox token set. It renders markup and CSS but does
not grant scripts, same-origin access, forms, popups, or top-level navigation.

## Java

The Java 8 path covers the application entry point, types/control flow, methods,
encapsulated classes, and generic collections. Source checks confirm requested
signatures and structures. Use BlueJ or JDK 8+ to compile and run completed files.

## C++

The C++ path covers the entry point and streams, typed control flow, functions and
references, vectors/standard algorithms, and classes with initializer lists and const
methods. Source checks are C++17-oriented; use a native compiler for diagnostics,
runtime checks, warnings, and sanitizers.

## Progress rules

- Required task: 25 Signal Energy.
- Bonus challenge: 40 Signal Energy.
- Completed lesson: 60 Signal Energy.
- A task and lesson award XP only once.
- Bonus tasks do not block lesson completion.
- Lessons unlock in track order, including transitions between worlds.
- Old IDs from NEXUS 1.0 are unchanged, so existing Python progress remains valid.
- Release 3.0 only appends new Systems Laboratory IDs; no earlier lesson, task,
  achievement, draft, or route identifier is renamed.
